# Architecture decision records

ADRs record durable choices, their safety consequences, and alternatives. Accepted
ADRs are not silently rewritten; material changes supersede them with a new record.

Current records include modular-monolith structure, PostgreSQL persistence,
deterministic risk gating, paper-by-default operation, fake-only V2 write boundaries,
and the GitHub OIDC/AWS architecture for the PAPER environment.
